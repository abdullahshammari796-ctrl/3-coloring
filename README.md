# Graph 3-Coloring Explorer

**BCS 309 — Algorithms I | Spring 2026 | Final Project**

Interactive web tool visualizing the Graph 3-Coloring NP-complete problem.

## 📂 File Structure

```
3-coloring/
├── index(5).html           ← Frontend (HTML structure & content)
├── style.css               ← Styling (CSS — colors, layout, animations)
├── script.js               ← Backend Logic (JavaScript — algorithms, quiz, charts)
├── index.html  ← All-in-one version (for submission)
└── README.md               ← This file
```

## 📋 What Each File Does

| File | Language | Lines | Role |
|------|----------|-------|------|
| `index(5).html` | HTML | ~450 | Page structure, content, layout |
| `style.css` | CSS | ~200 | Dark theme, bright beginner mode, animations |
| `script.js` | JavaScript | ~330 | Algorithms, graph drawing, quiz, charts |
| `index.html` | All-in-one | ~1100 | Complete app (HTML+CSS+JS) for submission |

## ⚠️ Important Notes

- **For GitHub Pages / LMS submission:** Use `index.html` (rename to `index.html`)
  - Your assignment requires: "All HTML, CSS, and JavaScript must be inside one file"
- **For studying / editing:** Use the split files (`index.html` + `style.css` + `script.js`)
  - All 3 files must be in the SAME folder to work

## ✨ Features
- Expert Mode + Beginner Mode (bright & colorful)
- 4 Algorithm Modes: Greedy, Backtracking, Brute Force, Compare
- Real-life story (phone towers in Dubai)
- 15-question shuffled quiz with study tips
- Multi-language code (Python, Java, C++, JavaScript)
- Growth curve charts
- NP-completeness proof with reduction diagram

## 🚀 Run Locally
Open `index.html(5)` (split) or `index.html` (all-in-one) in any browser.
